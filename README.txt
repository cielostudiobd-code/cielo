# Cielo Home — Updated Version

## Changes
- Removed the outer white/grey page area. The website now fills the viewport.
- Header button changed from SIGN IN to CONTACT US.
- Logo icon changed from star to the letter C.
- Added a dedicated hero GIF layer behind the "DISCOVER / COLLECT / FROM US" heading.
- Added scroll-reveal animations to headings, text, cards and images.
- All image areas now use real `.webp` files from `assets/images/`.
- Included editable WEBP placeholder images with different custom colors.
- Responsive desktop/tablet/mobile layout.

## Add your hero GIF
Put your GIF here:
`assets/images/hero.gif`

The HTML already loads it:
`<img src="assets/images/hero.gif" ...>`

You can replace that file with any GIF you want. If you use another filename, change the `src` in `index.html`.

## Change the WEBP images
Replace any of these files with your own WEBP image while keeping the same filename:
- `product-01.webp`
- `product-02.webp`
- `media-01.webp` through `media-06.webp`
- `feature-01.webp`
- `feature-02.webp`
- `feature-03.webp`

Or change the filenames in `index.html`.

## Change image colors
The supplied WEBP placeholders are only starter images. You can replace them completely with your own `.webp` files.
